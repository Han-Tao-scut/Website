About This BLAST Implementation

⚠️
This is a simplified local BLAST implementation for learning purposes. It performs sliding-window alignment scoring against gene sequences in the database. For production use, integrate NCBI BLAST+ or BioPython's BLAST wrapper.

The algorithm uses identity percentage, E-value (heuristic approximation), and bit score to rank hits. Results with ≥40% identity are reported, sorted by identity descending. Each search is logged in the database for analysis.
